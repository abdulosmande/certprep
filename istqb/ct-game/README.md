# CT-GaMe — Game Testing

English Sample Exam Set A v1.0.1 and all 14 appendix exercises, compatible with syllabus v1.0.1.

- Main exam: 40 questions, 40 points; pass mark 26 points.
- 60 minutes, with an optional 25% allowance (75 minutes).
- Multiple-answer questions require the exact correct selection to earn points.
- Submission reveals source answers and rationales; reset clears answers and restarts the timer.
- Appendix: separate untimed self-check practice, without an exam score.

Sources: `ISTQB_CT-GaMe_SampleExam_v1.0.1.pdf` and `ISTQB_CT-GaMe_SampleExam-Answers_v1.0.1.pdf` (21 October 2022). Format checked against `ISTQB_Exam-Structure-Tables_v1.19.pdf`. Copyright © ISTQB®; source authors are acknowledged on both pages and in the source PDFs.

Source discrepancy: question 22 has b) in the summary answer key, but a) in the detailed answer table. The detailed rationale explicitly supports a) and rejects b); the interactive exam uses a) and displays a note beside the question.
