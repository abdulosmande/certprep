# CT-AuT — Automotive Software Tester

German and English interactive versions of the supplied Set A v2.3 question and answer PDFs, based on syllabus v2.1. Copyright © ISTQB® / German Testing Board; source filenames are acknowledged on each exam page.

Both editions contain 40 single-choice questions worth 40 points. Pass mark: 26 points. Standard time: 60 minutes; optional 25% practice extension: 75 minutes. Source wording, options, correct answers and per-edition learning-objective / K-level tags are preserved independently. Tables are included as local assets or HTML, with image enlargement available. Answers and rationales appear after submission.
