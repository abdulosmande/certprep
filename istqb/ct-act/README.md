# CT-AcT — Acceptance Testing

Interactive exams for syllabus 2019:

- English Sample Exam Set A v1.2 (2 February 2022).
- German GTB Probeprüfung v2019 (25 June 2020).
- Each exam has 40 questions and 40 points; pass mark: 26 points.
- 60 minutes, with an optional 25% allowance (75 minutes).
- Source decision tables and process diagrams are preserved as local images that can be opened at full size.
- Submission reveals answers and source rationales; reset clears answers and restarts the timer.

Each language uses its own question and answer PDFs, since the editions differ. Source filenames and copyright credits appear on each exam page. Copyright © ISTQB® / German Testing Board e.V.; authors and translators are acknowledged in the source PDFs. German source licence: CC BY-ND 4.0.
