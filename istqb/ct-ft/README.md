# CT-FT — Finance Testing

English Sample Exam Set A v1.0, compatible with syllabus v1.0.

- 40 questions, 45 points; pass mark: 30 points.
- 60 minutes, with an optional 25% allowance (75 minutes).
- Multiple-answer questions require the exact correct selection to earn points.
- Submission displays source answers and rationales. Reset clears answers and restarts the timer.
