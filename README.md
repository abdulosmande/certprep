Appendix practice sets are untimed self-check exercises and do not receive an exam pass/fail score. Language columns contain independently sourced editions, not necessarily translations of the same question set. The catalogue groups all exams by language and syllabus; select a syllabus icon or name to reveal its available sets.

## Features

- ⏱ **Timed** — countdown timer with visual warnings at 15 min and 5 min remaining
- 🌐 **Practice time extension** — optional extra time; ISTQB exams offer +25%; CPRE offers 75 → 90 minutes
- ✅ **Instant feedback** — answers revealed with colour coding and explanations after submission
- 📊 **Score summary** — points earned, correct/wrong/skipped, time used, pass/fail verdict
- 🔁 **Reset** — restart at any time without leaving the page
- 📱 **Responsive** — works on desktop, tablet and mobile

## Exam format

Questions are taken directly from the official sample exam PDFs published by the respective certification bodies. Source wording, tables and diagrams are preserved; any documented source corrections are explained on the relevant exam page.

K-level and learning objective tags are shown on every question card. Point values follow each source exam; a K3 question may be worth one, two, or three points depending on the certification. CT-AuT Set A v2.3 has 40 single-choice questions worth one point each, a 26-point pass mark, and a 60-minute timer ([ISTQB exam format](https://www.istqb.org/certifications/certified-tester-automotive-software-tester-ct-aut/)).

Each language gets its own `EN/`/`DE/` subfolder per certification. Any image referenced by a question (tables, diagrams screenshotted from the source PDF) lives in a sibling assets folder next to the exam HTML file.

Advanced Agile Tester is in `istqb/ct-al-at/EN/`. Technical Test Analyst is in `istqb/ct-al-tta/EN/` (sample editions 4.0 and 4.2) and `istqb/ct-al-tta/DE/` (sample edition 4.0), with four additional untimed exercises per edition.

To add an exam, drop the HTML file (and its assets folder, if any) into the appropriate `EN`/`DE` folder and add a card inside the matching language and syllabus `<details>` group in `index.html`. Update the group count and the README catalogue. Create a new collapsed syllabus group when necessary.

## Validation and shared assets

Run `npm test` for syntax, answer-key ranges, source figures, links and catalogue coverage. Run `npm install` followed by `npm run test:browser` for scoring, keyboard/dialog controls, offline loading and mobile layout (Microsoft Edge by default; set `BROWSER_CHANNEL=chrome` for Chrome).

Fonts are bundled in `assets/fonts/` with their SIL Open Font License notices. Pages share catalogue navigation, accessible confirmation dialogs and contrast styles. Most existing ISTQB pages also share the deadline timer; the four new Advanced Agile/Technical Test Analyst pages use a shared exam engine. The downloaded project can run offline with its local assets.

Run `npm run test:practice` to check all appendix pages and the expanded catalogue at mobile width.

The TA v2.6 PDFs stored under the source DE folder are English duplicates of the EN source files; the English exam already covers them. They do not supply a separate German exam. Language columns contain independently sourced editions rather than guaranteed translations. Appendix practice pages are untimed self-checks.
