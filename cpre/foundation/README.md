German exams reside in `DE/`, with diagrams in `DE/assets/<source-stem>/`. The public-set version 3.3.3 identifies the questionnaire, not a syllabus version.

A questions award all points for the correct choice. P questions award proportional credit per correct selection; selecting more choices than requested earns zero. K questions award proportional credit per correctly classified statement. Passing uses the unrounded score: at least 49 of 70 points. These rules follow the [IREB examination regulations](https://hub.ireb.org/media/pages/resources/cpre-foundation-level-and-agile-primer-examination-regulations/a7858da873-1787039946/cpre_fl_and_primer_examination_regulations_en_v5.6.2.pdf).

The HTML provides keyboard controls, a deadline-based countdown, automatic submission, answer review, and reset. Added explanations are study notes, not official IREB rationales.
